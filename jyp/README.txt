#__version__="2025.10.04"

- 실행관련
1. 개발 과정에서 실행은 app.py를 이용
2. 배포판은 파일을 압축한 것이 아닌 런처(실행기exe)만 배포

- 구동 방식
1. 런처구동시 런처와 구글드라이브의 txt파일내의 버전정보 확인
2. 버전이 다를시 드라이브내의 zip파일 다운로드및 특정 폴더에(예:%appdate%폴더) 압축해제(업드레이드)

- 수시로 바뀌는 문서 (예:템플릿,벤리스트 등)
1. gas와 연동하여 실시간 반영
2. 드라이브내의 jyp폴더안에 json파일 형식으로 저장 및 파일교체(버전)
3. 교체방법 : 파일 우클릭 -> 버전관리 -> 새 버전 업로드 -> 닫기
※ 주의 : 파일만 교체하고 다른거 건드리지 말기 - 버전의 자체가 달라지면 주소가 달라져 gas부터 건드릴게 꽤 많아짐
